### Hi, I'm Oleksii

Python developer from Lviv. I mostly build LLM assistants, automations and bots, usually for a problem that I or people around me actually have.

| Project | What it is |
| --- | --- |
| [scribe-rag](https://github.com/spiowm/scribe-rag) | Telegram assistant that answers BEST Lviv members' questions from Notion and Google Drive, also available over MCP. Around 100 members have used it. |
| [flat-hunt](https://github.com/spiowm/flat-hunt) | Collects rental listings in Lviv from three sites, reads them with an LLM and scores them. The flat I rented came from it. |
| [2048-solver](https://github.com/spiowm/2048-solver) | Plays the monobank 2048 on a real phone. It reads the screen over ADB and picks moves with a Rust expectimax engine and an n-tuple network. Made the top 100. |
| [bee-monitoring-system](https://github.com/spiowm/bee-monitoring-system) | My bachelor's thesis on tracking bees at the hive entrance with YOLO11-pose and counting their traffic. |
| [app-time-chip](https://github.com/spiowm/app-time-chip) | Android app that shows how long you've been in an app next to the status-bar clock. |

Python, FastAPI, PostgreSQL, Qdrant, Docker, Gemini API, MCP, PyTorch, Kotlin.
